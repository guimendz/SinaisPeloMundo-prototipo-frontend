# Sinais Pelo Mundo - Front-end

Este repositório contém a versão inicial do front-end desenvolvida por mim para o projeto semestral "Sinais Pelo Mundo".

Minhas contribuições:
- Estruturação das páginas em HTML
- Estilização com CSS
- Implementação de funcionalidades em JavaScript

A versão final do projeto foi desenvolvida em equipe e encontra-se no repositório oficial:

https://github.com/bibichuzz/SinaisPeloMundo

Tecnologias utilizadas:
- HTML
- CSS
- JavaScript

## Sobre o projeto

Sinais Pelo Mundo é um sistema web desenvolvido como projeto semestral da faculdade, com o objetivo de conectar usuários proporcionando acessibilidade a serviços relacionados a viagens e turismo.
